## 本次修复

初测发现：容量为 1 的课程，两次并发请求都返回报名成功。修复后，数据库触发器在同一次写入中检查名额、重复和时间冲突；并发复测得到一份 active 和一份 waiting，取消后候补转为 active。

新增 `0002_booking_guards.sql`，配套 Worker 报名模块和 6 项 Worker/SQLite 内存数据库测试。与原 Node.js 测试一起运行，13 项通过。
