# 演示流程

1. 打开 `https://wenxiang-neijiang.pages.dev`；局域网演示可启动 `start-demo.bat`，打开窗口显示的地址。
2. 展示牛肉面插画：“一碗热面暖胃，一堂好课暖心。”说明这是面向内江银龄用户的演示原型。
3. 在 AI 选课助手输入“我是零基础，想学毛笔字，不想花钱，不想学音乐”。成功调用模型时显示“AI+规则”；展开条件与推荐理由，解释模型理解需求、程序筛选真实课程。若现场网络导致模型失败，据实展示“规则模式”。
4. 预约一门课程，打开“我的课程”。
5. 再预约时间冲突课程，展示阻止提示。
6. 点“大字模式”和“朗读课程列表”。
7. 点击“管理员”，新增一门容量为 1 的测试课程并导出报名名单。
8. 用其他演示用户报名同一课程，展示候补状态。

## AI 加分演示

- 课程详情点击简明介绍：说明 AI 改写介绍，时间、教师、地点和费用仍使用原始字段。
- 输入限制很多的需求，例如“周一晚上免费篆刻课”，展示无符合课程时的解释；不编造课程、不自动忽略限制。
- 输入不明确的需求，例如“我想参加活动”，展示补充问题与探索课程。
- 解释技术：受约束 JSON 解析、条件过滤、全部课次冲突检查、规则加权排序和超时回退。

## 演示前准备

课程使用固定示例日期。先确认课程在报名时间范围内；需要长期演示时在后台更新日期。测试课程使用“演示测试”名称，结束后下架。线上与本地报名数据各自独立，不能在两端切换时假定课表同步。
