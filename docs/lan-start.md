# 电脑和同一 Wi-Fi 手机访问

## 启动

1. 使用 Node.js 24，双击项目中的 `start-demo.bat`。
2. 保留服务窗口。电脑打开 `http://localhost:3000`。
3. 手机连接与电脑相同的 Wi-Fi，打开窗口显示的“同一 Wi-Fi 手机访问”地址。
4. 本次电脑地址为 `http://172.20.11.227:3000`。换网络或重启后地址可能改变，每次以窗口显示为准。

也可以在项目目录的 PowerShell 执行 `node server/index.js`。如果显示端口已占用，先尝试直接打开网页；同一个服务只需启动一次。

## 如果电脑能开、手机不能开

按顺序检查：

1. 地址使用 `http://`，带 `:3000`；手机不能使用 `localhost`。
2. 电脑服务窗口仍在，手机与电脑确实同网。
3. Windows 弹出防火墙提示时，只对可信任的专用网络允许 Node.js 通信；不要关闭全部防火墙。
4. 校园网或访客 Wi-Fi 可能禁止设备互访。可改用手机热点连接电脑，再看启动窗口的新地址。
5. 临时需要公网演示时直接使用 https://wenxiang-neijiang.pages.dev 。

## AI 与数据

本地报名保存在本机 SQLite，与公网 D1 分开。本地默认请求线上选课模型；请求中仅含找课文字或课程介绍。网络不通会显示规则模式，仍能浏览和报名。

完全离线运行：在项目 `.env` 中设置 `AI_REMOTE_URL=off`，关闭服务并重新启动。切换回线上模型时删除该行或改为 Pages 地址。

演示课程有固定报名截止日期。后续演示若已过期，应在管理员端调整日期；不要把过期无法报名误判为网络问题。
